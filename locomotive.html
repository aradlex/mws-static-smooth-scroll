🚀 Get Started with Locomotive

Ready to create immersive scroll experiences? Here's everything you need to get started.

🚀 Quick Start

// Load Locomotive Scroll
<link rel="stylesheet" href="libs/locomotive-scroll.min.css">
<script src="libs/locomotive-scroll.min.js"></script>

⚙️ Basic Setup

const scroll = new LocomotiveScroll({
  el: document.querySelector('[data-scroll-container]'),
  smooth: true,
  lerp: 0.1,
  direction: 'vertical'
});

// Add data attributes to HTML elements
// data-scroll
// data-scroll-speed="0.5"
// data-scroll-class="is-inview"
