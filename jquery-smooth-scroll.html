🚀 Get Started with jQuery Smooth Scroll

Ready to implement reliable smooth scrolling? Here's everything you need to get started.

🚀 Quick Start

// Load jQuery and plugin
<script src="libs/jquery.min.js"></script>
<script src="libs/jquery.smooth-scroll.min.js"></script>

⚙️ Basic Setup

$('a[href^="#"]').smoothScroll({
  speed: 800,
  easing: 'swing',
  offset: 0,
  beforeScroll: function() {
    console.log('Starting scroll...');
  },
  afterScroll: function() {
    console.log('Scroll complete!');
  }
});
